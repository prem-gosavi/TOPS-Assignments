
# CompTIA A+ — Troubleshooting and Helpdesk Assesment

## 📌 Overview

This assessment demonstrates practical and theoretical understanding of computer hardware components, system assembly, hardware compatibility, troubleshooting, and AI-assisted technical learning.

The assessment combines:

- Hardware component identification
- Motherboard ports and CPU socket identification
- RAM and storage installation
- Full desktop PC assembly
- BIOS and POST verification
- Hardware troubleshooting
- Workstation deployment and boot-failure diagnosis
- AI-assisted troubleshooting and checklist improvement

Practical activities were documented using photographs, BIOS/UEFI screenshots, labeled diagrams, and written explanations where applicable.

# Section C — Mini Capstone Project

## Workstation Deployment & Boot-Failure Diagnosis

The capstone project focuses on diagnosing a newly assembled workstation that fails to boot or reports hardware detection problems.

### 1. First Hardware Components to Check

The first components checked are:

1. **PSU and Power Connections**
2. **RAM**
3. **Motherboard and CPU**

These components are checked first because they are essential for powering the system and completing the POST process.

---

### 2. Motherboard–CPU Compatibility

Motherboard and CPU compatibility was considered using:

- CPU socket
- Chipset support
- BIOS support
- Supported CPU generation
- Actual motherboard and CPU installed in the system

---

### 3. RAM and Storage Verification

RAM installation was verified by checking:

- Correct DIMM slot
- Proper seating
- Locking clips
- RAM capacity detected in BIOS/UEFI
- POST status

Storage installation was verified by checking:

- SATA data connection
- SATA power connection
- NVMe M.2 installation where applicable
- Storage detection in BIOS/UEFI
- Operating-system detection

---

### 4. Hardware Installation Checklist

A preventive checklist was created covering:

- ESD precautions
- CPU/motherboard/RAM compatibility
- Power and data connections
- RAM and storage seating
- BIOS/UEFI hardware detection

---

### 5. SSD vs HDD Recommendation

SSD storage was recommended for modern office workstations because it provides:

- Faster boot times
- Faster application loading
- Faster file access
- Better overall system responsiveness
- No moving mechanical parts
- Quieter operation

# Section D — AI-Augmented Learning

## Step 1 — Build With AI

An AI tool was used to create a troubleshooting checklist for a desktop PC that fails to boot immediately after assembly.

The AI checklist covered:

- Motherboard
- RAM
- Storage
- PSU
- Troubleshooting priority
- ABC Solutions scenario

The exact AI prompt used for the assessment was documented.

---

## Step 2 — Test & Debug Without AI

The AI-generated checklist was reviewed manually.

One important improvement identified was the need to explicitly place **ESD and safety precautions before physical hardware troubleshooting**.

The troubleshooting order was also improved so that:

1. ESD and safety
2. PSU and power connections
3. RAM
4. Motherboard and CPU
5. Storage
6. BIOS/UEFI and compatibility

were checked systematically.

The original AI checklist, corrected checklist, and explanation of changes were documented.
