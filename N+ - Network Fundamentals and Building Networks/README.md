#  N+ - Network Fundamentals and Building Networks

# Introduction

This folder contains assignments completed as part of the N+ Network Fundamentals and Building Networks course. It covers networking concepts, network models, TCP/IP, IP addressing, subnetting, and network troubleshooting using Wireshark.

Assignments

### 1. Introduction to Networking and OSI Model
- Introduction to computer networking
- OSI layers and their functions
- Identification of OSI layers using Wireshark
- Real-world examples of the OSI model
